# Orion TTD Casework Testing Project Source Rule V0

## Purpose

The dedicated ChatGPT `TTD TESTS` Project is the design/review chat context for Command Language Casework.

Current default launcher target:

- `CASEWORK_DESIGN_PROJECT_URL_DEFAULT` in `tools/command-language-casework/scripts/launch-casework.sh`
- current default: `https://chatgpt.com/g/g-p-6a2d9ee3c5088191a02e4c72cd5f9f3b/project`

## Surface Split

- `TTD TESTS` Project: curated design/review chat context for choosing the next suite
- Casework GUI: validates suite JSON and copies the runner
- disposable runner tab: generic/source-free ChatGPT page that executes the runner only
- Orion repo study files: raw evidence, generated indexes, study status, and cumulative interpretation
- Command Center: mirror/cache/status source for fresh chats, not runtime authority

## Belongs In TTD TESTS Project

- Command Language Casework Designer Skill
- Runner Schema Skill
- Current Study Status Skill
- concise Casework tool source note
- legal/status authority notes only when relevant to the current study
- recent result review notes only when needed for the next suite

## Does Not Belong By Default

- broad Orion architecture sources
- unrelated mobile extension milestone docs
- whole Command Center dumps
- stale study statuses
- implementation logs unless the current study needs them
- secrets or private runtime data

## Authority Rules

- Study status and result evidence outrank broad project vibe.
- Project sources influence suite design, not scoring authority.
- Scoring and classification come from local repo code.
- The disposable runner tab should remain generic and source-free.

## Comparison Notes

- This differs from the broad Orion Browser Project because it is narrowed to test design/review sources only.
- This differs from Command Center because Command Center is memory/status/cache, not the working design chat context.
- This differs from the disposable runner tab because the runner tab should execute only, not carry curated sources.
